# 竞品分析、飞书平台规则与成本测算

## 一、飞书「万能文件入表」竞品盘点与差异化切口

市面上在飞书多维表格中做“文件/图片识别入表”的现有方案主要分三类，各自有明显短板：

1. **飞书官方「智能文档处理」插件**
   - 强项：增值税发票、名片、身份证、营业执照等标准固定票据。
   - 短板：遇到非标文件（供应商奇葩格式报价单、微信截图、简历、采购合同）无法适配，也无法将一份多明细文件拆成多行记录。
2. **插件市场的「批量文字识别 / PDF 转文本」插件**
   - 强项：把图片/PDF 转成纯文本塞进单个单元格。
   - 短板：不按目标表头拆字段，不对齐单选/多选/日期/数字类型，更不做数据核对。
3. **「字段捷径 + Coze/Dify 智能体」**
   - 强项：自由度高、适合有动手能力的技术型用户。
   - 短板（也是本插件最核心的差异化壁垒）：
     - **零配置**：无需自己搭工作流或写 Prompt，打开插件自动读取当前表头、选项与样例行。
     - **一文件拆多行**：一张报价单或聊天截图里有 8 行明细，自动拆成 8 条记录（字段捷径只能“一行进、同行出”）。
     - **人工复核安全阀**：写入前先预览，AI 低置信度、单选未命中、`数量 × 单价 ≠ 总价` 全部自动**标黄提醒**，支持就地编辑后再一键写表。

## 二、飞书开放平台规则（个人开发者上架与收费）

1. **开发与测试**：注册飞书开放平台开发者账号，即可本地运行侧边栏插件（飞书多维表格支持直接加载本地 `http://localhost:5173` 插件地址进行实时联调）。
2. **上架应用市场**：
   - **企业自建应用**：仅限自己所在团队内部使用。
   - **商店应用（公开分发）**：需提交应用中心审核，遵循权限最小化原则、提供隐私说明与使用文档。若涉及商用收费和对接微信/支付宝支付，建议注册一个低成本个体工商户或企业主体。
3. **收费与抽成机制**：
   - 飞书面向纯个人开发者的统一内置应用内购抽成体系尚未全面铺开；目前绝大多数独立开发者采用 **Freemium + 外部收款（License 激活码 / 独立账号按次或包月订阅）** 模式，平台不直接抽成。
   - 若未来接入飞书官方应用商店统一商业化计费组件，需按届时 ISV 商务政策执行。

## 三、多模态 API 成本与定价测算

以国产高性价比视觉大模型（如通义千问 `qwen-vl-max` / `qwen2.5-vl`、豆包视觉模型）为例：

- **单张图片 / 单页文档提取消耗**：约 1,500 ~ 2,500 Input Tokens + 300 ~ 600 Output Tokens。
- **单次 API 实际成本**：约 **¥0.005 ~ ¥0.02 元 / 页**（不到 2 分钱）。
- **建议定价策略（毛利率 > 80%）**：
  - **免费体验**：每月赠送 10~20 页额度（足够用户在模板里体验出爽感）。
  - **个人月卡 / 次卡**：¥19.9/月（含 300 页）或 ¥9.9 体验包（100 页，成本仅约 ¥1~2 元）。
  - **团队版 / 定制模板包**：¥99~199/月（不限人数或按团队额度包，适合电商/HR/采购小团队）。
